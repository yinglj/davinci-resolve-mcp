# DaVinci Resolve LibreChat 开发计划

## 目标
- 浏览器端提交剪辑任务并查看进度
- 后端拆解任务并调度MCP工具完成自动化编辑
- 任务数据和日志落地MongoDB
- 知识库支持检索编辑策略与素材语义信息

## 技术选型
- 前端：React + Vite + TypeScript（参考LibreChat前端）
- 后端：Node.js + Express + Socket.IO（参考LibreChat后端）
- 数据：MongoDB
- 知识库：Qdrant 向量数据库

## 编译与运行汇总
- 前端：npm install / npm run dev / npm run build / npm run preview 或 npm run start
- 后端：npm install / npm run dev / npm run build / npm run start

## 场景驱动编排分阶段计划
### 阶段1：素材输入与场景落库（已完成）
- 前端只选择场景与提交素材URL
- 后端统一生成MCP调用参数并落库
- 场景版本与素材清单写入任务

### 阶段2：素材接入与预处理（已完成）
- 素材URL接入与校验
- 本地上传与存储接入
- 素材元数据抽取与落库
- 任务执行前素材预检与失败阻断
- 轻量化布局：账号入口收敛至左下角

### 阶段3：智能编排与多工具流水线（待完善）
- 基于场景的多步骤编排模板
- MCP工具链执行编排与回滚策略
- 任务结果结构化与可追溯输出
- 工具分析与任务拆解API雏形
 - 引入图式编排（可选 LangGraph）实现状态机与可回滚执行
 - 节点：素材解析、节奏分析、风格应用、转场生成、渲染输出
 - 边：失败恢复与回退策略
 - 流水线：意图理解→计划生成→工具执行→结果验证→回填

## 开发规划
- 基础框架吸收：登录注册、菜单布局、对话/任务页面骨架
- 任务联动：对话指令生成任务、任务结果回填对话
- 用户中心：头像上传、资料编辑、权限与组织信息
- MCP工具编排：多步骤执行、错误恢复、重试策略
- 可视化增强：任务详情、历史对比、素材预览入口
- 对话能力：会话持久化、搜索、分享与收藏
